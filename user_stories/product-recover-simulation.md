# Keep my whole product when I return

As a product author, I want to keep my whole product when I return, so that I can try the complete product confidently.

## Acceptance criteria

1. Returning to my paused product keeps the selected parts, journey, saved data and remaining call allowance.
2. If setup fails, the instructions name my real source files and keep the product options in the retry command.
3. A request with an unknown result is read again using its existing identity and is never automatically sent twice.

## Verification scope

PDD CLI composition and orchestration. Cases: [native behavior cases](../test/product-composition/product-recover-simulation-cases.json). These are requirement drafts, not executed tests or a Runtime pass. Native integration must exercise the real public boundary and preserve all existing request, source and accounting guards.

# Keep simulator and guide context inside the ceiling

I can use the simulator and local advice without opening excluded project or scenario content. The same boundary applies when my guide refreshes or connects my agent.

Draft for review. These choices and expected results are not approved.

## Acceptance criteria

1. Project cards, product rules, code-presence facts, private scenarios, judges and input bindings use only permitted content, with incomplete coverage reported honestly.
2. Guide and bridge refreshes revalidate permission, remove excluded retained source context and validate required source before authentication, model metadata or connection.
3. Local contract catalogs and sibling footprints, shared-source and SVG advice, and binding coverage do not open excluded source or create new global refusal gates.
4. Every test, lint, Try, terminal, HTTP, MCP, retry and owner-access path applies the same required-source boundary before its authentication, network or dispatch work.
5. A bounded connected agent uses only the supplied packet; if its native tool and automatic-context controls cannot ensure this, connection fails locally with the reason and no provider switch.

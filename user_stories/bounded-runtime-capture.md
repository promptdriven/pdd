# Capture selected authored source inside the ceiling

I can test or simulate selected authored Stories without a second Git repository. I see the actual files to upload and a useful local refusal for a required file outside my boundary.

Draft for review. These choices and expected results are not approved.

## Acceptance criteria

1. An allowed simulation subtree permits only the selected complete in-bound source; selection forms and repository-relative reference meanings stay unchanged.
2. A required excluded file refuses before authentication, network, model metadata or dispatch and names the referring chain, requested target, boundary and remedy.
3. The same ceiling covers includes, recursive dependencies, test context, calls, contract and seed references, app maps, stylesheets and preparation inputs and outputs.
4. Excluded optional discovery and footprint files are not opened or a reason to refuse independent selected work; incomplete footprints cannot establish a current pass.
5. For stable source, --files names the actual upload paths and sizes; separate non-upload reads are disclosed, and a changed capture snapshot is retried consistently.
6. Existing unconfigured behavior, secret, regular-file, symlink and ancestor, size and stricter write or executable safeguards remain in force.

## Rules to check

Every required path must satisfy both source safety and the ceiling before access. Excluded required content cannot be silently pruned. Forbidden: rebasing a reference to the allowed directory, opening excluded content before discovery filtering, or substituting a partial footprint. Exact tar and native read events must be checked independently.

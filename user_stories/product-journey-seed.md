# Start my journey with the right data

I can start a journey with its chosen data and see whether it has passed.

## Acceptance criteria

1. My journey starts with its chosen values over the product and part starting data, including an explicit empty value.
2. Two parts claiming to write orders stop my Try before anything is uploaded.
3. My current J1 result counts as one passed journey; J10 does not count as another J1.

## Rules to check

Native integration must bind current journey evidence to actual selected-source identity through the existing Story evidence owner; a supplied evidence reply proves aggregation, not native capture/history. Seed merging preserves all own JSON keys, explicit nulls/arrays and lossless numeric values under the shared contract-reference rules.

# Repo hygiene and offline PDD lint

Own `src/repo-hygiene-lint.mjs` (thin facade), `src/core/lint/*.mjs`, and `src/shared/glob-match.mjs`. Run 100% offline, deterministic, structural PDD lint in `<1s` with zero AI calls, zero network calls, zero batch-state writes, zero `autopilot/` imports, and zero `runtime-seam` imports. Semantic prose, clarity, and port-parity review belong in AI lint (`pdd lint --ai`), not offline regexes.

## Domain decisions

- **Strict Layer-1 DAG:** `src/core/lint/*.mjs` imports only peer `src/core/lint/*`, Layer-1 core helpers (`file-owner`, `story-lint`, `product-documents`, `svg-layout`), and Layer-0 `src/shared/*`. Linear DP glob matching (`compileGlobMatcher`, `matchGlobSegments`, `normalizeGlob`, `MAX_GLOB_WILDCARDS`) lives in Layer-0 `src/shared/glob-match.mjs` so `changed-map`, `prove`, and `verify-paths` reuse it cleanly. Test-code sleep and skip checks live in Layer-2 `src/autopilot/lint-sleep-skip.mjs`.
- **Workspace scope and safety:** Resolve `realRoot = realpathSync(root)`, list Git-visible paths once via `gitFiles(realRoot)` unless `files` is supplied, resolve `workspacePolicy` from `workspacePolicy` / `workspaceRoot` / `realRoot`, exclude secret paths (`isSecretPath`) and paths outside `workspace.allows`, and skip `fixtures/` unless explicitly selected. Open regular in-root files with `O_NOFOLLOW | O_NONBLOCK` and verify `dev`/`ino` parity without throwing on unreadable, escaping, symlinked, binary, or oversized files.
- **Single-pass I/O and upfront scope resolution (`src/core/lint/lint-scope.mjs`):** Build ONE upfront reporting scope before running checks while ALWAYS keeping the full repository lookup index for resolving prompt links, headers, dependencies, scenarios, and ownership (so unchanged linked prompts or files never trigger false missing-dependency or broken-header errors). Bare `pdd lint` uses full-repository scope. `pdd lint <targets...>` scopes strictly to targeted files plus their directly linked prompt/Story/scenario/owned-code/app-map closure without pulling in unrelated sibling Stories or untouched broken files. `pdd lint --diff [BASE]` computes `BASE..WORKTREE` changes FIRST (committed + staged + unstaged + untracked + renames/deletions, failing closed if base is unavailable), removes working-tree deleted paths from the live lookup index, follows **old paths on renames and deletions** so callers/headers/dependencies/app-maps/scenarios referencing a deleted or renamed file ARE included in scope and flagged, and scopes ALL checks strictly to that closure. Share single-pass file caches across `lintRepoProject` and `lintSvgLayouts`. Read only the 4 KiB header window of eligible production code files to check `broken-prompt-header` and resolve prompt ownership.
- **4-part agent-teaching diagnostics:** Every `error` finding — and every `warn` finding that supplies a fix hint — includes location (`path:line [code]`), invariant violated, a concrete 1-line `Fix:` (citing `pdd` skill guide names or `pdd help prompting`, never fake repo-relative `skills/pdd/references/` paths), and a `Rerun:` command (default `pdd lint`).
- **Offline CLI handler (`runLocalLint`):** Computes `--diff [BASE]` first when requested, resolves one upfront `LintScope`, runs `lintRepoProject`, scoped `.ui.svg`/app-map/scenario structural checks (`svg-layout`, forwarding scoped `promptPaths`, `appMapPaths`, and `scenarioPaths` with `includeShortDiagnostics: true`, and promoting compact-scenario compile refusals to `problems` in 4-part `Error: scenario: <path>:1 [compact-scenario-compile] ... Fix: ... Rerun: pdd lint` form so broken compact scenarios exit `1`), optional base-trusted `lint.commands` loaded strictly from `git show <baseSha>:pdd.json` (skipping untrusted working-tree command edits unless `--trust-working-tree` is explicitly requested), and opt-in `upstream-linters.mjs` (`includeUpstream` defaults to `false` so slow external compilers never run on the default `<1s` `pdd lint` path unless explicitly requested).
- **Unmistakable 1-line offline summary:**
  - When `problems.length === 0`: print `Lint OK: N prompt(s), M story/scenario(s), K app-map(s), J drawing(s) validated offline (0 errors, W warning(s))` to `stdout` with empty `stderr` and exit `0` (using `0 warnings` / `1 warning` / `W warnings`).
  - When `problems.length > 0`: print errors to `stderr`, print `Lint FAILED: N prompt(s), M story/scenario(s), K app-map(s), J drawing(s) validated offline (E error(s), W warning(s))` to `stdout`, and exit `1`.
  - `--json` emits `{schema_version: 'pdd.local-lint.v1', ok, exit_code, local_only: true, summary_line, counts: {prompts, stories, scenarios, app_maps, drawings}, problems, warnings, findings, diff?, commands?, upstream_linters?}`.

## Built-in deterministic structural rules

| Rule IDs | Default | Target | Invariant |
| --- | --- | --- | --- |
| `lint-config-invalid` | `error` | `pdd.json`, `rules/lint/*.json` | Valid JSON, schema (`disable`, `rules`, `scenario`, base-trusted `commands` <= 16 and `mutation_command`), no symlinks. |
| `broken-prompt-header` | `error` | Production code headers in scope | Every `// Prompt: <path>` or `// Generated from <path>` header points to an existing Git-visible `.prompt.md` file (path-only; ignores sha256 staleness). |
| `broken-dependency-link` | `error` | Prompt `## Dependencies` in scope | Every relative Markdown link resolves to an existing Git-visible file or directory with exact letter case (explicitly flags case mismatches before Linux CI). |
| `broken-relative-link` | `error` | Prompt Markdown links in scope (outside `## Dependencies`, code fences, and inline code spans) | Every relative CommonMark link resolves to an existing Git-visible file or directory with exact letter case (explicitly flags case mismatches before Linux CI). |
| `truncated-markdown-fence` | `error` | `.prompt.md` and lintable Stories in scope | Every opened Markdown fenced code block (```` ``` ```` or `~~~`) has a matching closing fence before EOF. |
| `truncated-markdown-table` | `error` | `.prompt.md` and lintable Stories in scope | Every data row inside a closed-pipe GFM table (`| ... |`) ends with a closing `|` rather than terminating mid-cell. |
| `app-map-whole-event-ref` | `error` | `app-map.json`, `app/maps/*.json`, and scenario `app_maps` in scope | Handler and timer `input` bindings must not use whole-event `{"$ref": "/event"}`; use a specific field pointer such as `"/event/value"`, `"/event/key"`, or a literal value. |
| `prompt-malformed-operations-cell` | `error` | `.prompt.md` `## Operations` tables and `Calls:` entries in scope | `Calls` cells/lines must not carry trailing parenthetical prose (e.g. `None (...)` or `mod.op (...)`), and `Error codes` cells must not attach trailing parenthetical prose after `None`/`N/A`. |
| `story-missing-criteria` | `error` | Story in scope | Stories include `## Acceptance criteria` with >= 1 item outside Markdown fences and HTML comments. |
| `diff-conflict-marker`, `diff-shadow-bin`, `misplaced-test-prompt` (in `--diff`) | `error` | `BASE..WORKTREE` diff | No merge conflict markers in non-doc files, no tracked/untracked/on-disk shadow runtime binaries under `node_modules/.bin/`, and no newly added/modified misplaced test prompts. |
| `duplicate-owner`, `misplaced-test-prompt` (repo-wide), `lint-config-untrusted`, `inverted-native-only-dependency` (checkable prompt linking a `kind: native-only` prompt under `## Dependencies`), `prompt-dependency-cycle` (across all non-fenced relative `.prompt.md` Markdown links outside `## Caller navigation` / `## Consumer navigation`), `prompt-missing-title`, `prompt-missing-dependencies`, `story-unbound-criteria` (binding both filename stems and explicit `story_path` in `story-criteria-parity.mjs`), `scenario-oversized` (default `max_steps: 15`, `max_world_bytes: 16384`, and lower-bound calls vs default per-request cap via [Scenario size hygiene](scenario-hygiene.prompt.md)), `product-prompt-inventory-drift`, `product-boundary-unwired`, `product-boundaries-unparseable` | `warn` | PDD files in scope | Advisory structural and graph checks configurable to `"off"`, `"warn"`, or `"error"` via `pdd.json` (in `--diff` and `pdd prove`, merge-base `pdd.json` and `rules/lint/*.json` control disables/weakenings and untrusted overrides emit `lint-config-untrusted`). |

## Project lint config (`src/core/lint/project-config.mjs`)

`loadProjectLintConfig` loads workspace-local `rules/lint/*.json` before `pdd.json` `"lint"`:
- `disable`, `rules`, `scenario` (optional `{ max_steps, max_world_bytes }` positive integer overrides for `scenario-oversized`; invalid values fail closed with `lint-config-invalid`), `commands` (up to 16 repo-native linter commands allowed only in merge-base `pdd.json`, never in `rules/lint/*.json`), and optional `mutation_command` (nonblank formal mutation-control command string allowed only in merge-base `pdd.json`, never in `rules/lint/*.json`). Legacy `custom_rules` regex DSL entries are ignored without compiling user regexes.
- `loadBaseTrustedLintOverrides` reads merge-base `rules/lint/*.json` and `pdd.json` so `pdd lint --diff` and `pdd prove` ignore untrusted working-tree/branch rule disables, severity weakenings, or `lint.scenario` threshold relaxations.

## Structural `--diff [BASE]` checks (`src/core/lint/test-inventory.mjs`)

- Diffs `BASE..WORKTREE` (failing closed when base comparison is unavailable; includes tracked changes plus untracked non-ignored files), catches shadow binaries under `node_modules/.bin/`, `.venv/bin/`, or `venv/bin/` (`diff-shadow-bin`), leftover merge conflict markers (`diff-conflict-marker` via line scan and `git diff --check`), and newly added/modified misplaced test prompts (`misplaced-test-prompt`), and reports advisories for `*.snap` edits and test-harness / `pdd.json` / `rules/lint/*.json` / `scripts.test` / CI edits.

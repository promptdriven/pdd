# Local PDD Alpha command boundary

PDD Alpha supplies a guide and recipes for the user's existing coding-agent conversation. Keep `pdd` as the command name. This is an authorized refinement to the previous public client: preserve useful local discovery while removing every connected/private command and dependency.

The local command surface includes help (root and known local command help), `--version`, `--skill`, `workflow list [--json]`, `completion bash|zsh`, `session [--agent codex|claude] [request text]`, and `workflow feature|bug|small-change [--agent codex|claude] [request text]`. Unknown or excluded commands, including with help flags, refuse clearly with exit2 before effects. There is no installed-Host lookup, adapter, forwarded argv, private import, private authentication implementation, private PDD network calls, account changes, private session launcher/engine, Runtime operation or installer. Public local workflow run/resume may use ordinary authenticated Git/GitHub tools through the distinct runner. Do not preserve dead private command declarations or validators.

Keep one catalog authoritative for help/parser/completion. Parse before local reads. Success returns0; unsupported syntax2; missing guidance/local filesystem failure1. Do not echo untrusted input. Local discovery reads do not create project files. Explicit session launches only the installed native Codex or Claude; native keeps the user’s existing environment/login and follows their conversation instructions. The controlling first-publication decision authorizes full-access launch modes owned by [native session](native-session.prompt.md) and [workflow stage transport](workflow-stage-herdr.prompt.md); no global permission or configuration rewrite is performed. No private managed workflow service or fallback. Package metadata/lock must be dependency-free, retain bin `pdd`, include complete docs/skills/recipes/example and avoid lifecycle scripts. Source use and private temporary package-consumer tests are supported; registry publication/global installation are outside scope.

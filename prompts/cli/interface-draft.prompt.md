# Draft missing Runtime interfaces

Own `src/interface-draft.mjs`. Preserve prompt prose and all existing blocks. Export `runInterfaceDraft({words,all,json,cwd}, ports)`, `interfaceFindings({root,paths})`, `runtimeCoverage({root,paths})`, `missingInterfaces(root)` and `runAutomaticApproval({path,root,tests}, ports)`.

Draft only Git-visible regular in-repository prompt files in the runtime workspace. Resolve explicit paths from cwd. Refuse unsafe paths, malformed blocks, unknown paths and --all combined with paths before any write. With --all select all workspace prompts, excluding nested fixture projects. Without --all require at least one path. Continue across independent draft failures and report each result. Never overwrite a block or choose native-only for the user.

Infer entry names and complete input/result schemas from explicit JSON interface declarations in the prompt or declared schema/contract dependencies. Resolve contract references with the shared contract reader. Existing module exports may supply clear operation names, but never invent types from names. No AI, authentication, program execution or network. Never invent limits or assume missing calls/resources are empty. Missing declarations remain draft gaps. If a complete declaration cannot be derived, write a partial draft with available operations and explicit draft gaps. Gaps refuse local lint and automatic approval. Do not manufacture empty schemas to report success. Keep the prose bytes unchanged. Fill the draft's prose hash after insertion. Store drafting provenance under .pdd/, outside Git: original prose, draft interface and Git head identities. These are evidence, not approval.

Lint every selected block locally through preflight and shared contract expansion. Return per-path state (drafted, existing or refused), problems and lint_clean. Print drafted, existing, lint-clean and refused counts. JSON contains the same results and exit_code. Exit 0 only when every selected block lints clean; exit 4 for block or drafting problems; exit 2 for usage/repository/path problems. Drafts are not approved.

Automatic approval accepts only a complete draft made by this command whose committed prose and all existing source still match its provenance. Reject native-only, gaps, an edited interface, new prose and strict approval mode for the selected prompt. Committing unchanged drafted blocks does not make them new behavior. Compare source with the recorded original tree while checks use the current source and current head. Other unchanged blocks from the same bulk draft may remain draft or already be approved; verify their stored draft identity and committed original prose instead of treating those metadata additions as new behavior. Require a native test command that names existing committed tests; run it from the repository through the execution port. Require exit 0 and then a complete prompt check on every existing Story test that reaches this prompt, using the normal runtime client. Include every discovered test variant of each affected Story, even variants that could not be parsed. Refuse unreadable or invalid variants before checking. No missing tests, cached passes, unknown/not-run/refused rows, partial checks or absent passing counts qualify. Recheck source identities after both runs. Evidence includes command, native exit, current source and prose hashes, prompt-check rows and route automatic-check-pass. Use the shared approval writer only after this evidence is complete; roll back a prompt write if journal recording fails. Never convert this to a person's approval or call it from draft/setup. Prompt and native checks remain separate evidence.

## Inventory results

`missingInterfaces(root)` returns sorted paths of workspace prompts with no block. `interfaceFindings({root,paths?})` returns `{code,path,section?,message}` rows for absent, malformed, stale or schema-invalid blocks, including draft gaps. Its default paths are workspace prompts outside nested fixture projects. `runtimeCoverage({root,paths?})` uses the same default scope and returns `{checkable,total,native_only}`. Total counts every selected prompt; checkable counts valid current full or partial blocks with entries; native_only counts valid current native-only declarations. Invalid, stale, missing and incomplete blocks remain only in total. A stale hash must not hide draft gaps: report both findings, so local lint still refuses the unresolved contract. Neither helper makes a network call or claims a server lint pass.

Native test commands for automatic approval are `node --test TEST...`, `npm test` or `npm run SCRIPT`. Node paths must name committed tests (a test/tests directory or a .test/.spec filename). npm scripts must be test or test:* and must exist in the committed package. Require a completed TAP report with a positive test count, all tests passed and zero failures. Retain those native counts with the command and exit code; a no-op or build is not native-test evidence. Run the chosen command as arguments, with no shell interpolation. Hash source bytes without decoding binary files.

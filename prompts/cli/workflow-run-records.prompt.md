# Workflow run records

Own `src/workflow-run-records.mjs`. Keep the journal authoritative and expose read-only run discovery for the CLI. Append one small derived entry per new run to `~/.pdd/runs/index.jsonl`; malformed or incomplete index lines are ignored. Resolve a repository from the nearest ancestor `.git` (including a linked worktree pointer) and its `commondir`, so a main checkout, any PDD run worktree and any subfolder share one identity. A repository lookup reads its main checkout and linked worktree journals. A machine lookup reads the index and each saved journal. Stage rows retain start/end times, agent and worktree; when Herdr did not persist a native session, match the agent's session files by exact cwd and a timestamp inside the stage window. Exactly one match yields `{agent,id,source:'session-file'}` and a reopen command; zero or multiple matches stay null with a reason. Readers never start or mutate a run.

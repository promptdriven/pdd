# Compiled Story checks

`src/compiled-test.mjs` exports async `runCompiledTest({root, words, json}, {stdout, stderr, spawn})`. `root` is the invocation working directory, `words` selects Stories, and `json` selects JSON output. `stdout` and `stderr` are writable streams; `spawn` is an injected synchronous process runner, defaulting to Node's `spawnSync`. The function returns exit code 0 only when the commit is known and every selected Story passes, 1 for failure or not run, and 2 when selection is empty or contains unknown or untested Stories. File access, Git and process execution are outside-world operations; no AI or interpreter call is made.

Discover scenarios using the project workspace and Git-visible source rules. Apply the ordinary local preflight admission to each scenario, including Story identity, partial scenarios, prompt status and prose hash, schema validity, actual criterion texts and coverage, and input schemas; a malformed, incomplete, stale or inaccessible scenario is not run. A missing implementation warning alone does not refuse interpreter admission. A native-only interface is not run and reports its declared reason. Resolve path selections from the invocation directory before applying preflight selection at the Git root; bare Story names remain names. Directory selections include untested Stories beneath that directory as not run, including when no tested Story matches. Bound directory matches to descendants, combine multiple selections without duplicates, and do not treat paths outside the project as all Stories. Explicitly named untested Stories remain selection errors. Do not follow source symlinks or output symlinks outside the workspace. Each tested entry names `implementation: {"kind":"cli","command":"node bin/tip.mjs"}`. Both input and result schemas carry the `cli` convention. Only resource-free, call-free entries and scenarios with an empty initial world, simulation, and step simulation overrides can run; other steps are not run because their outside world cannot be faithfully supplied. Referenced or unsupported inputs are not run. The command is whitespace-separated argv with no shell; reject command strings containing quotes, escapes, shell metacharacters, newlines or glob characters. Append the step's string argv, pass optional string stdin (default empty), and capture exit code and exact UTF-8 stdout and stderr with a ten-minute timeout and 10 MiB output cap. A launch failure or timeout is not run. Only `equals` checks of `result` pointers `/exit_code`, `/stdout`, and `/stderr` are supported; any other check makes the step not run. Compare every supported check exactly.

The JSON report and `.pdd/code-test/latest.json` have `target: "code"`, `commit` (the Git HEAD SHA, or null if unavailable), `ai_calls: 0`, `dirty` (true for uncommitted tracked or untracked worktree changes, false for a clean worktree, or null when Git cannot determine it), and `stories` in selection order. Each Story has `story`, `status` (`passed`, `failed`, or `not run`), and `steps`. A step has `step_id`, `status`, and either `reason` for not run or `checks`. Each check has `criterion_id`, `path`, `status` (`passed` or `failed`), `expected`, and `actual`. A Story fails if any step fails, otherwise is not run if any step is not run, otherwise passes. Text output prints each Story's status, path, commit and dirty state, with reasons for steps not run and failing checks (scenario path, `step_id`, `criterion_id`, `path`, `expected` and `actual`). JSON output prints the complete report on stdout. Record the report locally for both output modes; missing commit cannot pass the command. Do not represent a not-run step as passed.

## Dependencies

[Runtime preflight](runtime-preflight.prompt.md) supplies Story selection, source boundaries, scenario shape, entry parsing, and schema checks. [Scenario JSON](scenario-json.prompt.md) owns exact integer scenario parsing and serialization. [Workspace](runtime-workspace.prompt.md) owns workspace access rules. These are required context for this checker.

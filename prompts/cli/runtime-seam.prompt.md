# PDD to Runtime seam

Own `src/runtime-seam.mjs` and the stable launcher entry `src/try-doors.mjs`. `src/runtime-seam.mjs` is the sole module in pdd outside `src/runtime/` permitted to import `src/runtime/`, and it is the compatible entry for pdd code and tests: while direct `src/runtime/` functions require their ports, `src/runtime-seam.mjs` fills every host port with pdd's behavior. Every pdd module in `src/`, `bin/`, and `scripts/` accesses Runtime commands, local format and workspace readers, check-plan and outcome helpers, and constants exclusively through `./runtime-seam.mjs`.

The seam keeps stable pdd-owned file paths for anything pdd writes into a user's files or passes to a child process:

- `src/try-doors.mjs` re-exports `runShim` from `./runtime-seam.mjs` so `.pdd/try/bin/<program>` launchers keep a stable pdd-owned module path across upgrades and package extraction.
- `runTry(input, ports)` in `src/runtime-seam.mjs` defaults `ports.tryLauncherUrl` to the `file:` URL of `src/try-doors.mjs` before delegating to `src/runtime/index.mjs`, preserving an explicit `ports.tryLauncherUrl` when provided.

## Request metadata and host ports

Because `src/runtime/` imports nothing outside `src/runtime/`, `src/runtime-seam.mjs` builds caller request metadata and host ports lazily on invocation. Legacy and canonical port spellings (`readEvidenceEligibility` and `evidenceEligibility`; `rememberSecrets` / `redactSecrets` and `redaction`; `agents.{loadDefinitions,list,ask}` and `{loadAgentDefinitions,discoverAgents,askAgent}`) are normalized before installing seam defaults so an explicit caller override under either name wins, and every seam default uses nullish fallback (`??`) so an own `undefined` property never erases a default. A single shared host `redaction` port (`{ remember, redact, known }`) backed by `src/secret-redaction.mjs` keeps host and Runtime redaction on one registry:

- `runJobs(input, ports)`: loads the host client companion graph (`src/product.mjs` and `src/command-catalog.mjs`) inside the guarded call and supplies `client.commands` (`{ test, lint, simulate }`) from `src/command-catalog.mjs` (`NAMES`).
- `buildCheckPlan(input, ports)`: supplies `ports.headerPrompts` from `src/file-owner.mjs`.
- `composeProductTry(input, ports)` and `selectJourneys(tests, selector, ports)`: supply `ports.parseProductDocuments` and `ports.parseProductWorldWriters` synchronously from `src/product-documents.mjs` (the pure parser leaf re-exported by `src/product.mjs`) and `ports.selectTests` from `src/test-selection.mjs`.
- `findTests(input, ports)`, `captureSource(root, options, ports)`, `createStrictSourceAccess(root, workspace, ports)`, `selectTests(found, words, options)`, `whyNoTests(root, visible, found, ports)`, and `readAgentScenarios(input, ports)`: supply `{isStoryPath, hasAcceptance, expectedTestPath, matchTests, orphanSummary, selectTests, whyNoTests, NO_TESTS}` from `src/test-selection.mjs`, binding preflight's `captureSource`, `findTests`, `allowsRuntimePath`, and `interfaceBlocks` onto `selectTests` and `whyNoTests`.

- `createTryGuide(options)`: supplies `ports.redaction` from `src/secret-redaction.mjs`, `ports.evidenceEligibility` synchronously from `src/workflow-eligibility.mjs` (`readEvidenceEligibility`, re-exported by `src/workflow-runner.mjs`), and selection ports from `src/test-selection.mjs`.
- `buildProjectCard(input)`: supplies `evidenceEligibility` (`readEvidenceEligibility`) synchronously from `src/workflow-eligibility.mjs` when omitted.
- `runCheck(input, ports)`: loads all check port-provider and host companion modules (`src/secret-redaction.mjs`, `src/file-owner.mjs`, `src/workflow-runner.mjs`, `src/workflow-runs.mjs`, `src/workflow-results.mjs`, `src/svg-layout.mjs`, `src/screen-compare.mjs`, `src/product.mjs`) unconditionally when invoked and supplies on every call: `client.version` from `package.json` when omitted (direct `src/runtime/` callers without `client.version` or `ports.clientVersion` get `null`, never a hardcoded literal), a lazy `ports.workflowBaseSha({ root, env })` callback backed by `ports.allRuns` / `src/workflow-runs.mjs` (`allRuns`) evaluated inside `runBatch` at check-plan time (preserving an explicit `input.workflow` only when supplied by the caller), `ports.headerPrompts` from `src/file-owner.mjs`, `ports.redaction` from `src/secret-redaction.mjs`, `ports.evidenceEligibility` from `src/workflow-runner.mjs` (`readEvidenceEligibility`), `ports.allRuns`, `ports.assessNativeEvidence`, `ports.usableResult`, and `ports.resultLines` from `src/workflow-runs.mjs` and `src/workflow-results.mjs`, `ports.lintSvgLayouts` from `src/svg-layout.mjs`, and `ports.compareScreen` and `ports.formatScreenComparison` from `src/screen-compare.mjs`.

- `runTry(input, ports)`: supplies `ports.tryLauncherUrl`, `ports.redaction` from `src/secret-redaction.mjs`, `ports.loadAgentDefinitions` from `src/agent-config.mjs`, `ports.agentBridge` delegating to `createAgentBridge` (so `src/agent-adapters.mjs` loads when the agent bridge opens, before `"Connecting your agent to the Try page…"` and `GET /model`, while preserving an explicit `ports.agentBridge` including `false`), fallback `ports.discoverAgents` from `src/agent-adapters.mjs` and `ports.askAgent` backed by seam `askAgent`, `ports.evidenceEligibility` from `src/workflow-runner.mjs`, `ports.parseProductDocuments` and `ports.parseProductWorldWriters` from `src/product.mjs`, and `ports.askApproval`, `ports.lineReader`, and `ports.promptPath` from `src/prompt-approve.mjs`.
- `createAgentBridge(context, test, tryId, options, link, seamPorts)`: loads `src/agent-adapters.mjs` (`discoverAgents`, `runAgentProcess`) before network access and supplies default `redaction`, `loadAgentDefinitions`, `discoverAgents`, `runAgentProcess` (`agents.run`), `askAgent`, and `guidePorts.evidenceEligibility` without cloning `context`.
- `readTryOwner(input, ports)`, `createTryTools(input, ports)`, and `runMcp(input, ports)`: supply `ports.tryLauncherUrl`, `ports.redaction` from `src/secret-redaction.mjs`, `ports.evidenceEligibility` (`src/workflow-runner.mjs` via `await import()` in async entries and `src/workflow-eligibility.mjs` in synchronous `createTryTools`), and `ports.parseProductDocuments` and `ports.parseProductWorldWriters` (`src/product.mjs` via `await import()` in async entries and `src/product-documents.mjs` in synchronous `createTryTools`) so MCP owner tools and Try reopening support whole-product simulations without passing top-level-`await` ESM graphs to `createRequire`.

- `readContractHistory(input, ports)` and `runContracts(input, ports)`: supply `ports.evidenceEligibility` synchronously from `src/workflow-eligibility.mjs` (`readEvidenceEligibility`) and selection ports from `src/test-selection.mjs`; `runContracts` also loads `runtimeClientSlice()`, while async CLI dispatch loads `src/product.mjs` and `src/workflow-runner.mjs` via `await import()` inside its error guard so `pdd contracts` preserves its client companion module set and load-failure handling without `createRequire` on top-level-`await` graphs.
- `migrateRuntimeWorkspace(input, ports)`: supplies `ports.evidenceEligibility` from `src/workflow-runner.mjs` (`readEvidenceEligibility`) and selection ports from `src/test-selection.mjs`.
- `saveDoorCaseResult(root, saved, options)`, `saveDoorCase(root, saved, options)`, `acquireCaseWriteOwnership(input, ports)`, `applyPendingCase(input, ports)`, `applyPendingCaseWithHandoff(input, ports)`, `savedStoryEvidence(input, ports)`, `createSavedStoryEvidenceReader(ports)`, and `runtimeWorkspaceMigrationStore(input, given)`: supply selection ports from `src/test-selection.mjs`.
- `runAutomaticApproval(input, ports)`: loads its approval-policy and check companion providers in base order (`src/approval-policy.mjs`, `src/prompt-approve.mjs`, `src/product.mjs`, `src/secret-redaction.mjs`, `src/file-owner.mjs`, `src/workflow-runner.mjs`, `src/workflow-runs.mjs`, `src/workflow-results.mjs`, `src/agent-config.mjs`, `src/svg-layout.mjs`, `src/screen-compare.mjs`) and invokes Runtime's `runAutomaticApproval` inside an outer `try/catch` error boundary that writes `${error.message || 'Approval failed.'}\n` to `ports.stderr ?? process.stderr` and resolves to `4` on any load or setup failure before Runtime's own guard. Supplies `readApprovalPolicy`, `approvalActor`, `readPromptApprovals`, and `recordPromptApproval` from `src/approval-policy.mjs`, `approvePromptText` and `promptPath` from `src/prompt-approve.mjs`, and seam check ports (`client`, `headerPrompts`, lazy `workflowBaseSha`, `allRuns`, `assessNativeEvidence`, `usableResult`, `resultLines`, `redaction`, `evidenceEligibility`, `lintSvgLayouts`, `compareScreen`, `formatScreenComparison`, selection ports, exit-code ports, and `promptTestsLabel`), preserving an explicit `workflow` only when supplied by the caller.
- `checkRuntimeHealth(input, ports)`, `loadRuntimeClient()`, `runtimeOrigin(env)`, and `runtimeClientSlice()`: `checkRuntimeHealth` and `loadRuntimeClient` supply `ports.redaction` from `src/secret-redaction.mjs`; `runtimeOrigin` delegates synchronously to `src/runtime/index.mjs`; `runtimeClientSlice()` loads `src/runtime/runtime-client.mjs` synchronously via `src/runtime/index.mjs` and overlays the seam-bound `acquireCaseWriteOwnership`, `applyPendingCase`, `applyPendingCaseWithHandoff`, `checkRuntimeHealth`, `createSavedStoryEvidenceReader`, `readContractHistory`, `runtimeOrigin`, `runtimeWorkspaceMigrationStore`, `saveDoorCase`, `saveDoorCaseResult`, and `savedStoryEvidence` bindings without importing host modules from the seam at module-evaluation time.

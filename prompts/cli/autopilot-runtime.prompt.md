# Automatic Runtime failure incidents

Own `src/autopilot-runtime.mjs`. #3147 authorizes this module. Runtime checks stay required. A Runtime failure parks only affected runs; other runs and checks continue. Do not add a client queue or throttle. Make no prompt or workflow approvals and no model calls.

Export `runtimeEvidence(run)`, the JSON identity for blocker.evidence below. Export `classifyRuntimeFailure(check,health=null)`: return null or a stable cause slug. `check` is a `readRunResults` pdd test record with batch, at, states and tests. Any failed row, binding refusal, active check, local expectation, file-rule refusal, or exhausted test budget (`provider-call-cap` or `call-cap-reached`) makes the result non-Runtime. A call-cap result is not auto-retried. Classify only saved service causes: timeout, stopped runner, provider error, server refusal and explicit no-verdict rows. Read timeout language from reason/error fields, never test filenames. Prefer an explicit valid health cause/code; healthy, access, absent health and health errors do not erase batch evidence. Never use raw messages or request IDs as a deduplication key.

Export async `reconcileRuntimeIncidents(state,ports,config,runs,{localOnly=false}={})`: return a Map from run number to runtime blocker. Runs are the caller's owned runs. Ports inject `now`, `readCheck(run)`, `busy(run)`, `health()`, `save()`, optional `reportRuntimeCause({cause,marker,title,runs,runtimeOwner})`, and `issueClosed(issue)`. The launcher binds these to saved-result, health, guarded-state and shared-reporter ports. The shared reporter owns issue routing, deduplication, creation and update, including the private team Runtime destination and the public PDD report destination for end-user machines. Never create or edit Runtime issues in this module. When the report adapter is absent or returns no confirmed issue, keep the affected run parked with `until:null`; a later qualifying check verdict can still wake it. Do not claim that issue filing is connected until the caller wires the shared port.

Classify stopped/waiting/paused runs without independent questions or unrelated explicit blockers. Read other owned runs' checks for recovery. Per-run read, health or reporter failures do not abort other runs. Persist `state.runtimeIncidents = {causes,seen}`. `seen` maps runId/batch/cause identities to observation times. Each cause record has cause, checkKind (`pdd test`), firstAt, failures (identity to observation epoch ms), runs (unique runId/batch attempts, each retaining `{runId,number,batch}`), issue (null or `{number,url,repository}`), lastFailureAt (failure observation time, not the check batch start), dirty (the shared reporter must update or reopen the cause), and optional recoveredAt. A blocker is `{kind:'runtime',until:String(issue.number)|null,cause,batch,checkKind,evidence}`; evidence identifies current parkReason, runtimeWait, gate and done.check. An observation of a new batch replaces evidence without resetting park age.

On a full tick, call the shared reporter once for each dirty cause and pass its affected runs plus the optional runtime owner. Save the cause before calling the reporter. Accept only a confirmed positive issue number and URL; retain the reporter's repository in the blocker for closure reads. The reporter owns dedupe after restarts and uncertain outcomes. A reporter error keeps the cause dirty and parked. Skip issue-closure recovery while a report or reopen is still dirty, so a failed reopen cannot make a closed issue look recovered.

For recovery, require a terminal verdict whose batch started after `lastFailureAt`. `check.at` is the batch start, while `lastFailureAt` is when the failure was observed. An overlapping batch that started before that observation cannot recover the cause. Closing the reported cause issue also recovers it. If the same failed batch remains after recovery, treat the new observation as another incident, clear recoveredAt and update/reopen the shared report before any wake. A local-only tick keeps matching blockers and reads local evidence but does not classify or report new failures, contact health or read issue state. Wake through ordinary oldest-first capacity and journal custody. The notice asks the worker to read its saved receipt, then send only no-verdict rows once with their original call caps. It never starts a paid check from this tick. Preserve uncertain-paid-request safety and all passed/failed rows.

## Dependencies

No required shared policy. All outside work uses the ports above.

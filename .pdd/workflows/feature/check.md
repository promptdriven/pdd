# Check the prompt

Use the installed PDD release's supported prompt-check command, as shown by `pdd --help`, against the current prompt and Story. Review the expectations before running the check. Report the exact revision and observed result, including failed, inconclusive, and unavailable cases.

A prompt check does not prove the generated code. If the installed release has no supported check for this prompt, mark the step unavailable and continue only when the person can still assess the draft safely.

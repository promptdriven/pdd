# Choose a visual direction

For a feature with a visible interface, show two or more meaningfully different design directions that cover the main task and relevant empty or error states. Explain the differences in plain language and keep labels readable at phone and desktop widths. Use the person's selection as a design direction for the prompt and Story.

The visual is a design sketch. It does not prove that the implemented interface behaves that way. For a feature without a visible surface, state why a visual is unnecessary and continue.

# Try the behavior when useful

Recommend a Try when a person can learn from exercising the proposed behavior, especially for a visible or interactive change. Use only a Try path supported by the installed PDD release. Keep the exact prompt and Story revision attached to the observation.

The person may try the proposed behavior before deciding on the Story. A design picture, saved link, or incomplete preview is not an interaction result. If Try is unavailable or cannot cover the criterion, state that plainly; do not claim it ran.

# Prepare the Prompt PR

When prompts changed, prepare a Prompt PR containing the approved prompt and Story plus the relevant authored examples and check evidence. Use only a PR method supported by the installed release or the repository's normal contribution process. The person reviews and merges the current revision.

Wait for that prompt revision to land before implementing code against it. A prompt with no change needs no Prompt PR; record the reason in the Story and continue with the already accepted contract.

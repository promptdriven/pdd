# Prepare and review the Code PR

Prepare a Code PR with the implementation, focused tests, applicable vector replay, formal evidence if any, and limitations. Link the accepted Story and current prompt revision. Use only a PR method supported by the installed release or the repository's normal contribution process.

The person reviews the diff and evidence for the current PR revision. If the revision changes, recheck what the change invalidated and request a current review. Keep missing evidence visible; do not turn it into a pass.

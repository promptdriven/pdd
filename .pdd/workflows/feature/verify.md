# Run the real project tests

Use the project's documented native test command to execute the independent cases against the implementation. Run relevant regression tests and required checks. When practical, prove a new test detects the targeted wrong behavior in a disposable copy; restore or discard that copy afterward.

Report the exact commands, exit status, results, revision and untested criteria. Do not turn an unavailable command into a pass or label code tests as prompt execution or general formal verification. If the project already has a relevant formal method, report its assumptions, scope and actual result separately.

# Review the correction with the person

Show reproduction evidence or its honest limit, the proposed correction, prompt/Story, independent regression expectations and any remaining risks. Use the person's existing authorization for this scope. Ask for a decision only when implementation is not yet requested or a material requirement remains unresolved.

Do not treat a test result as the person's approval or reuse an approval of different behavior. This is ordinary conversation review, with no phone or PDD approval command.

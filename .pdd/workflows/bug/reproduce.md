# Reproduce the reported behavior

Read the report, contributor instructions and accepted behavior contract. Use the smallest safe local input that demonstrates the difference between expected and actual behavior. Record setup, input, expected result, actual result and the command used.

If reproduction would require unavailable access or external effects, explain the limit and ask only for needed evidence. Do not infer a cause from a symptom or claim an unexecuted reproduction. Preserve the failing input for a regression test.

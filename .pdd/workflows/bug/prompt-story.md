# Write the corrected prompt and Story

Read the [Prompting guide](../../../docs/prompting-guide.md). Identify the owning canonical prompt. State the corrected behavior and each forbidden outcome as observable Story criteria. Preserve the actual bug input as an example and write expected outcomes from the accepted contract, not from a model response.

For each criterion that can be evaluated against a prompt, include a focused authored vector using a format already supported by the project. Name criteria that cannot be modeled. If the prompt already expresses the expected behavior, leave it unchanged and explain why the fix belongs in code or another source.

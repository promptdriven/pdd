# Replay vectors and run checks

Replay accepted vectors against the implementation using a project-supported method. Run the regression test and other required checks for the affected surface. Keep the prompt result, code result, and any formal result separate; report actual commands, revisions, and outcomes.

When formal analysis applies and a supported checker is available, state its assumptions and scope. Formal evidence does not replace tests or person review. Report unavailable evidence as unavailable, and name criteria that remain uncovered.

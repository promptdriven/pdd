# contracts

For medium and large products, write `contracts/*.md` with one owner and a JSON
schema under each `### record` heading. Write `contracts/world.md` with each key,
its meaning, sole writer, readers and write rule. Put the shared seed in
`contracts/seed-world.json`. Check normal, refusal and empty-world examples.
Leave unresolved choices visible for the person. For small products, skip this.

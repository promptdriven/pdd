# parts

Read the approved map. For medium and large products, write the Boundaries and
Runs tables in `product/plan.md`. Give each part its prompt folder. Name what
crosses each boundary and what never crosses. Keep each run small; its Needs
column names the plan PR or earlier runs. For large products, name each slice's
journey and make slice 1 the thinnest path through every part.
For a small product, keep only the map and say "run one feature run".

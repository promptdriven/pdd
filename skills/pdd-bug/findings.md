# Findings input

Before `pdd workflow done reproduce`, write `<run-folder>/bug-findings.json` as UTF-8 JSON. This is new input, not workflow state or an approval. Use actual observations and agent-selected semantics; never invent evidence or a cause.

The JSON object has exactly `version` (integer 1), `runId` (the current saved run ID), `repository` (canonical OWNER/REPO), `issue` (positive current issue number), `reproduced` (boolean), `cause` (object or null), `search` (`complete` or `unavailable`), and `relations` (array in agent order). On success `cause` has exactly nonblank strings `file` (safe repository-relative path), `function`, `flaw` (one sentence) and `class` (short name). On failed reproduction `cause` is null and `relations` is empty; never guess. `search: unavailable` cannot assert an empty completed search. Each relation has exactly `issue` (positive other issue number in this repository), `classification` (`needs`, `same cause`, `same class`, `duplicate`, `related`), `quote` (nonblank short exact text), `source` and `effect`. `source` is either `{kind:"issue",repository,issue,revision}` or `{kind:"comment",repository,issue,comment,revision}` or `{kind:"code",repository,path,revision}`; issue and comment IDs are positive integers, repository is canonical, path is safe repository-relative, and revision is the nonblank current content revision supplied by the existing evidence owner. Disallow traversal, absolute paths, symlinks escaping the verified checkout, foreign repositories and source identities outside the selected relation/current issue. Quote matching is exact, case-sensitive and without normalization.

`effect` is exactly `{kind:"none"}`, `{kind:"blocked-by",dependent,blocker}`, `{kind:"sub-issue",parent,child}`, or `{kind:"duplicate",duplicate,canonical}`. Endpoint values are positive issue numbers in this repository. Every effect endpoint must be the run issue or the selected other issue, except an explicitly selected existing Class parent for sub-issue. The agent supplies endpoints and direction; `blocked-by` requires `needs` and an explicit necessary-before judgment; `duplicate` requires classification `duplicate`. Class parent choice and creation/discovery are agent decisions; this contract requires an existing `Class:` parent and never substitutes the distinct Global fix umbrella. All other combinations are held, not silently converted. No effect creates a self-link or changes unrelated issues.

A quote is evidence of its existence, not proof of the classification. Supply the observed content revision of the cited source, not a guessed revision. If a source or revision is unavailable, do not invent it. An empty completed search and an unavailable search are distinct.

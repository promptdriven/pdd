# Set up PDD

The public installer is coming soon; no install command is published in this guide yet. The source repository is not the runtime package, and the release instructions will state the supported distribution and features when they are available.

In the project repository, inspect its `AGENTS.md`, `CLAUDE.md`, or other contributor instructions before changing files. Then run `pdd --help` to see the commands available in your installed release. Follow the help output for setup and use; do not assume commands from another version are supported.

If a PDD runtime check is unavailable in the installed release, continue with prompt and code work that does not depend on it, and label that check unavailable. Do not substitute an unverified local script or claim the check passed.

To use PDD from a phone, run `pdd phone` in the terminal. It displays the web app link or QR code. Open the link on your phone, then use the browser's Add to Home Screen option if desired. The phone is the person's device; the terminal command only shows the link or code.

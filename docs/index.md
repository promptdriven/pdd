# PDD documentation

PDD is a prompt-first way to describe and check software behavior alongside its implementation. This public source repository contains the CLI and user-facing guidance. The built PDD runtime is distributed separately; it is free to use with PDD and may not be copied or resold. Runtime source and private schemas are not included here, and a feature is available only when the installed release supports it.

Start with [setup](setup.md), then use `pdd --help` to see the commands supported by the installed release. The root README lists the public command catalog.

Read the [Prompting guide](prompting-guide.md) before authoring prompt contracts. Use the [prompt sessions guide](prompt-sessions.md) for the person-reviewed path from a prompt change to code, and the [workflow index](workflows.md) to choose a recipe. [Checks and formal evidence](checks.md) explains what each kind of evidence can establish.

To open PDD on your phone, run `pdd phone` to show the web app link or QR code, then open that link on your phone. Use the browser's Add to Home Screen option if you want an icon. The command only displays the link or code.

# Command line

Use `pdd --help` as the source of truth for the commands available in the installed release. The root README lists each supported public command with a one-line description; it is maintained against the CLI command catalog.

When help reports a subcommand, consult that command's own help before using options. Record the actual command and result when reporting a check. If help does not list a command, do not infer that it exists from an older release or another installation.

`pdd phone` displays the web app link or QR code when that command is available. Scan or open the link on your phone; the terminal does not become the phone app.

# pdd-cli

`pdd-cli` is the Python package for [`@promptdriven/pdd`](https://github.com/promptdriven/pdd). It installs the `pdd` command and runs the matching `@promptdriven/pdd` release.

## Requirements

- Node.js `>=22.16.0` on `PATH` ([nodejs.org](https://nodejs.org))

## Install

```sh
pip install pdd-cli
pdd --version
```

You can also install `pdd` directly with npm:

```sh
npm install -g @promptdriven/pdd
```

## Documentation

Read the full setup and usage guides at [github.com/promptdriven/pdd](https://github.com/promptdriven/pdd).
